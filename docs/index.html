Bench2Drive Leaderboard interactive

A community-maintained list of methods evaluated on Bench2Drive v0.0.3, self-reported from each publication. Beyond Driving Score (DS) and Success Rate (SR), this view lets you slice methods by the expert whose demonstrations they were trained on, which sensor modalities (and how many of each) they consume, and whether their output is a spatial path or a spatiotemporal trajectory.

About the new fields

Expert
The privileged ground-truth driving policy whose rollouts supervised the method via imitation learning — typically Think2Drive (the original Bench2Drive dataset expert), PDM-Lite, or LEAD. Methods trained purely by RL, or where this isn't specified, are marked accordingly.
Modalities
Which of camera / lidar / radar / language the architecture consumes as input, with how many (e.g. "6 surround cameras", "1 LiDAR"). A single discrete navigation command is not counted as "language" — only free-form text / VLM-style instruction or reasoning counts.
Output
Spatial: the model predicts only an ego trajectory / waypoints / control, with no explicit forecast of other agents. Spatiotemporal: the model jointly forecasts the future motion or occupancy of the scene (other agents, BEV future states) as part of its pipeline before planning.

These three fields are not in the original Bench2Drive benchmark output — they were compiled by reading each paper and are seeded only where that could be done with reasonable confidence (hover a badge for the one-line justification and a link to the source paper). Everything else is marked unknown on purpose rather than guessed. If you know a method's correct values, please open a pull request against docs/data.js in the repo — same workflow as adding a new method to the main table.

Results are self-reported, copied from the respective publications. Methods below the divider use privileged ground-truth perception. See the repository README for the full methodology.
